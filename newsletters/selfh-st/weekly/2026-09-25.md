## Weekly Highlights

Keen-eyed readers will notice a new section in the newsletter this week – [a self-hosting-themed puzzle](https://selfh.st/weekly/2026-09-25/#weekly-puzzle). Inspired by the [free daily games from the NYT](https://www.nytimes.com/crosswords?ref=selfh.st), it's another way to spotlight self-hosted projects that isn't just a bulleted list of news and software.

If you sign in (it's free!) before you play, I'll also be tracking streaks for those who complete each week's game before the next issue drops – so get solving! (This week's game is a [Strands-like word search](https://www.nytimes.com/games/strands?ref=selfh.st) and requires JavaScript, so email readers will need to hop over to the web to play.)

On a semi-related note, I'm taking credit for the Stirling PDF team's [removal of their OAuth SSO paywall](https://github.com/Stirling-Tools/Stirling-PDF/releases/tag/v3.0.0?ref=selfh.st) after launching an [SSO filter for selfh.st/apps](https://selfh.st/apps/?sso=enterprise) last week.

The unexpected move is a refreshing change of pace from the past few weeks, which have seen projects like [Planka](https://github.com/plankanban/planka/releases/tag/v2.2.0?ref=selfh.st) and [Grist](https://github.com/gristlabs/grist-core/releases/tag/v1.7.18?ref=selfh.st) pull SSO from their community editions. And while I still stand by a developer's right to charge for pretty much whatever they'd like, it's nice to occasionally see a project move in the opposite direction, even if it's not entirely clear what prompted it (goodwill, competitive pressure, a well-timed directory filter...).

You're welcome.

- [LibreOffice 26.8 and interoperability: preserving what cannot yet be read - TDF Community Blog](https://blog.documentfoundation.org/blog/2026/09/17/libreoffice-26-8-and-interoperability/?ref=selfh.st) - LibreOffice 26.8 adds basic support for importing and exporting a range of chart types that Microsoft Office includes in OOXML files: box-and-whisker, funnel, Pareto, radial, treemap and waterfall charts. LibreOffice is unable to display or edit these charts, but it does recognise them, informs the user that the chart type is not yet supported, preserves the underlying definition unchanged, and rewrites it when the file is saved. At first glance, this appears to be an admission of incompleteness, whereas it is actually an example of what implementing a proprietary format entails when the aim is interoperability – for the benefit of users, rather than a commercial strategy that treats users as mere tools. What happened Microsoft added these chart types to Office from 2016 onwards, storing them in a namespace generally referred to as ‘chartex’. The namespace is not part of the ISO/IEC 29500 text approved as an international standard, but is documented separately in Microsoft’s extension documentation. This is entirely legal and perfectly normal commercial behaviour: a vendor improves its product and the file format evolves accordingly. The consequence, however, is that the format in everyday use is no longer the one that was standardised. The ISO number continues _(TDF Community Blog / Italo Vignoli)_

## Content Spotlight

Meet **lldap**, a lightweight, self-hosted LDAP server. Built for users looking for the benefits of centralized authentication without the complexity of a full-fledged LDAP server, **lldap** offers a simplified, *opinionated* take on the protocol that's easy to configure and manage via a minimal web interface. Features include user and group management, self-service password resets, LDAPS support, and compatibility with a [wide range of popular self-hosted services](https://github.com/lldap/lldap/blob/main/example_configs/README.md?ref=selfh.st).

**lldap** can be [easily deployed via Docker](https://github.com/lldap/lldap/blob/main/docs/install.md?ref=selfh.st) and doesn't require additional containers, with optional support for MySQL and PostgreSQL over the default SQLite.

## Command Line Corner

Use the **column** command to view the contents of a file in an organized table or column format with options for specifying delimiters, width, names, alignment, and more.

In the example below, **column** is being used to display the example.txt file using a comma as the delimiter for the table.

```bash
$ cat example.txt
  Task,Completed (Y/N)
  Research,Y
  Setup,Y
  Deploy,N
  Analyze,N
$ column example.txt -t -s ","
  Task       Completed (Y/N)
  Research   Y
  Setup      Y
  Deploy     N
  Analyze    N
```
