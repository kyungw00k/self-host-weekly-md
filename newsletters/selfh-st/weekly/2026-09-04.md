## Weekly Highlights

It was a relatively slow news week in self-hosting, so before I jump into the typical recap, a few points of housekeeping:

- The AI-assisted tag for projects has been temporarily dropped as too many users are confusing 'AI-assisted' for 'vibe coded'. I'm working on a new methodology for tagging projects that will be rolled out in the next week or two.
- If you're using LLM-generated text to communicate with me or submit content, I'm going to ignore it. Life is busy and I get wanting to automate things, but I cannot stomach the LLM-isms and cadence of the sentences they produce.
- I'm migrating the infrastructure that powers [selfh.st/apps](https://selfh.st/apps) and have temporarily paused adding new projects. Everything should be back up and running early next week.

With that out of the way – in actual news and activity:

- **SourceHut** announced they're following in [Codeberg's footsteps](https://blog.codeberg.org/protecting-our-floss-commons-from-llms.html?ref=selfh.st) and [prohibiting LLM-generated source code](https://sourcehut.org/blog/2026-08-27-tos-changes-and-llms/?ref=selfh.st#changes) on the platform
- **File Browser** has [officially been archived on GitHub](https://github.com/filebrowser/filebrowser?ref=selfh.st) after announcing the project [will no longer be maintained](https://hacdias.com/2026/07/28/filebrowser/?ref=selfh.st) just a few weeks ago
- As if the **BentoPDF** project couldn't get any cooler, the developer [open sourced their new PDF standards and compression engines](https://github.com/alam00000/bentopdf/releases/tag/v2.8.8?ref=selfh.st) in the platform's latest release
- The **YOURLS** team (URL shortener) accidentally tagged a release incorrectly and followed up with [this hilarious response](https://github.com/YOURLS/YOURLS/releases/tag/1.10.6?ref=selfh.st)
- **Debian** [published the results](https://lists.debian.org/debian-devel/2026/08/msg00307.html?ref=selfh.st) of its recent vote on AI-assisted contributions, with "Responsible Use of Generative AI" winning out among the nine potential resolutions
- If you're still using **Plex**, you should [update your server and clients ASAP](https://forums.plex.tv/t/important-security-update-for-plex-media-server-v1-43-2-and-earlier/942319?ref=selfh.st)
- I'm finding it increasingly difficult to [take online interactions seriously anymore](https://www.reddit.com/r/selfhosted/comments/1w1fmde/i_built_the_selfhosted_equivalent_of_ssotax_11/p6km475/?ref=selfh.st). Is everyone a bot now?
- Have you ever found yourself wondering if a certain GitHub user is a virgin? Wonder [no more](https://github.com/KasaBranca/IsHeVirgin?ref=selfh.st)...

Happy **selfh.st**/ing!

## Content Spotlight

Meet **MinusPod**, a self-hosted platform for podcast ad removal. With **MinusPod**, users can transcribe podcast episodes with Whisper via local or hosted LLMs to detect, cut, and rebuild ad-free episodes. Features include a web interface, cost analytics, pattern detection across episodes, audio cue detection, and podcast metadata and publishing tools.

**MinusPod** can be [deployed via Docker](https://github.com/ttlequals0/MinusPod/blob/main/docs/installation.md?ref=selfh.st) and ranges in complexity based on the selected LLM provider (local vs hosted).

## Command Line Corner

Use the **cd -** command to easily navigate back to the previous directory when traversing folders:

```bash
$ cd /some/path
/some/path$ cd /another/path
/another/path$ cd -
/some/path$ _
```
