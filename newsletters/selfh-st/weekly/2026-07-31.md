## Weekly Highlights

Over the last year, exploring and digesting content for this newsletter has become more demanding than ever. My content submission form receives upwards of 25+ submissions *a day *(keep them coming!), and controversial topics like vibe coding, GitHub, and Immich's lack of mobile tag support haven't made it any easier.

Despite this, for the first time in months this past week, I found myself completely immersed in a new-ish application ([BookBridge](https://github.com/cporcellijr/bookbridge?ref=selfh.st)) that automatically syncs reading progress across audiobooks and ebooks. And while I'm still ironing out the kinks, the euphoria from getting it to work for the first time was a refreshing reminder of what got me into this hobby in the first place.

If this is you, I'm officially granting you permission to skip the unnecessary maintenance this weekend, unplug from the rest of the internet, and dive into that app you've been dying to spin up ([or find one TikTok-style](https://roamers.dev/?ref=selfh.st)).

## Content Spotlight

Meet **OpenTogetherTube**, a self-hosted platform for remote YouTube watch parties. With **OpenTogetherTube**, users can stream synchronized videos with remote friends via dedicated virtual rooms with share links. Features include custom share URLs, text chat, SponsorBlock integration, support for various video sources (YouTube, Vimeo, .mp4 file streams), voting, themes, and more.

**OpenTogetherTube** can be [easily deployed via Docker](https://github.com/dyc3/opentogethertube/blob/master/docs/how-to-deploy.md?ref=selfh.st) and requires separate PostgreSQL and Redis containers for data storage and memory caching.

## Command Line Corner

Use **Ctrl + x + e** to instantly fire up an editor from the command line. By default, the shortcut will open a blank editor – but its usefulness shines when entered along with a line of text, which will automatically appear in the first line of the editor after hitting **Ctrl + x + e**.

This is particularly handy when running complex commands that may need to be documented for future reference.

```bash
$ _

_


$ echo -e "correct\horse\battery\staple"

echo -e "correct\horse\battery\staple"_
```
