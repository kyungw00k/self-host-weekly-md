## Weekly Highlights

Happy Friday! Last week's puzzle launch was a resounding success (over 2,000 completions!), but I also received a ton of helpful feedback from some who found it confusing. To help, I've since added a hint system and more robust instructions on how to play (check it out below!).

I've also been working on a system for tagging vibe coded projects, something many of you have been *very vocal* about since the AI-assisted tags were dropped from the newsletter a few weeks ago.

Unfortunately – like everything else – the topic is incredibly nuanced:

- Most projects are using AI in some capacity, and too many readers were mistaking *AI-assisted *for *vibe coded *when evaluating the software lists below
- I don't have the capacity to correctly identify every project – there are simply too many submissions, and sometimes it's not obvious (some devs use AI for their READMEs but not code, etc.)
- Some readers *want* to see popular vibe coded projects – not because they're going to deploy them, but because they can be inspirational for their own personal projects

I *think* I've come up with a decent solution to address all of the above, but I'm still ironing out the kinks. Thanks for your patience in the meantime.

## Content Spotlight

Meet **Tagr**, a self-hosted music metadata and tag editor. Designed as a browser-based alternative to popular desktop apps, **Tagr** offers an intuitive web interface that can be used to browse, edit, and manage audio file tags from just about anywhere. Features include support for editing 40+ metadata fields, custom metadata, album art management, star ratings, track/disc numbering, barcodes, and a read-only display of audio file properties (codec, bitrate, etc.).

**Tagr** can be [easily deployed via Docker](https://github.com/suitux/Tagr?ref=selfh.st#quick-start-with-docker) and doesn't require additional containers.

## Command Line Corner

Add the **-p** flag (--parents) to the **mkdir** command to create a directory of new folders in a single command instead of repeating it multiple times for each new folder:

```bash
$ mkdir -p /self/host/weekly
$ tree
  .
  |___self
      |___host
          |___weekly
```
