## Weekly Highlights

This week, [two critical PHP vulnerabilities](https://mashable.com/tech/php-vulnerability-security-update-explained?ref=selfh.st) (dubbed PHParr PHP2SHELL) that could allow code to be remotely executed on servers were leaked ahead of their planned patches, causing a portion of the internet to blip on Wednesday. PHP [quickly moved up the patch releases](https://www.php.net/archive/2026.php?ref=selfh.st#2026-10-21-5) in response.

If you deploy PHP-based applications (handy list of apps [here](https://selfh.st/apps/?language=PHP)), you should update them ASAP ([Unraid, too!](https://docs.unraid.net/unraid-os/release-notes/7.3.4/?ref=selfh.st)).

In other news and activity:

- My [annual self-host user survey](https://selfh.st/survey/2026-open/) officially crossed 5,000 responses and will remain open until October 31st for those who haven't completed it yet
- **Plex **[reportedly laid off their player development team](https://forums.plex.tv/t/2026-20-0-beta-ios-and-tvos-4k-dovi-hdr10-won-t-play-infinite-spinning-circle/943966/92?ref=selfh.st), and the now former employee who shared the news [had some (now removed) advice for users](https://i.imgur.com/87huC1b.jpeg?ref=selfh.st) (see also: [PLEX2SHELL](https://zmain.info/blog/plex2shell?ref=selfh.st))
- **Linus Torvalds** [made his first (known) AI-assisted contribution](https://www.tomshardware.com/software/linux/linus-torvalds-posts-his-first-llm-assisted-patch-to-the-linux-kernel-after-issuing-clear-pro-ai-directives-the-bossman-makes-use-of-ai-tooling-himself?ref=selfh.st) to the Linux kernel
- The **Omnivore** team [reminded everyone](https://www.reddit.com/r/selfhosted/comments/1xaujlk/omnivore_a_fully_selfhosted_and_open_source/?ref=selfh.st) that – despite the platform shutting down last year – [it can still be self-hosted](https://github.com/omnivore-app/omnivore?ref=selfh.st)
- [OpenBSD 8.0](https://www.openbsd.org/80.html?ref=selfh.st) was released, which brings new GPU support, ARM64 hibernation support, wireless network driver improvements, and more to the platform
- A new [non-root local server for Roborock vacuums](https://github.com/Python-roborock/local_roborock_server?ref=selfh.st) has been making its rounds
- [CleanYourTV](https://github.com/Gathin23/cleanyourtv?ref=selfh.st), a tool for debloating Android-based TVs, went viral on social media

## Content Spotlight

Meet **PatchMon**, a self-hosted Linux patch monitoring platform. With **PatchMon**, users can easily monitor a fleet of Linux machines for security patches and deploy them directly from a web-based dashboard. Features include agents for remote deployments, one-click approvals, scheduled patches, selective patching, Docker monitoring, patch history, and audit logs.

**PatchMon** can be [easily deployed via Docker](https://patchmon.net/docs/patchmon-operator-guide?ref=selfh.st#installing-patchmon-server-on-docker) and requires external PostgreSQL and Redis services for data storage and background job queues.

## Command Line Corner

Press the **.** key while holding **Alt** to cycle through and reuse *arguments* from previous commands:

```bash
$ docker compose up -d some-docker-container
$ docker compose stop <Alt .>
$ docker compose stop some-docker-container
```
