## Weekly Highlights

If you missed it, I posted the results of the **2026 Self-Host User Survey** this week (link below). Thanks again to all who participated – in total, it received 6,221 responses (a 52% increase from last year's 4,081 🚀).

With so many more participants than last year, it's difficult to tell whether certain shifts reflect real trends or just a different mix of respondents. Regardless, there were a number of results I found particularly interesting:

- The number of Portainer deployments [has *shrunk* since last year](https://selfh.st/survey/2026-results/#management-platforms) and is now neck-and-neck with Dockhand – a platform that was only released [*earlier this year*](https://github.com/Finsys/dockhand/releases/tag/v1.0.14?ref=selfh.st)
- Debian and Ubuntu are [wildly more popular](https://selfh.st/survey/2026-results/#linux-distributions) than distributions like Fedora and Arch (this year's survey marked the first appearance of this question)
- 63% of respondents [avoid vibe coded apps](https://selfh.st/survey/2026-results/#ai-assisted-projects), 25% don't mind them, and 7% avoid AI-assisted projects altogether (the rest answered 'it depends' or 'other')
- Forgejo surpassed Gitea as the [most popular self-hosted Git platform](https://selfh.st/survey/2026-results/#git)
- Proton Drive (storage) usage [has grown significantly since last year](https://selfh.st/survey/2026-results/#cloud-storage-providers) (it'll be interesting to see how it makes out next year given [its CEO's recent headlines](https://www.zdnet.com/tech/can-you-still-trust-proton/?ref=selfh.st))
- The [number of laptop deployments](https://selfh.st/survey/2026-results/#hardware-options) has now surpassed that of server clusters
- 733 respondents are still [YOLO'ing their application updates](https://selfh.st/survey/2026-results/#update-methodology)
- Three people who responded to the survey [are over 80 years old](https://selfh.st/survey/2026-results/#age-range) (hell yeah!)

And lastly, everyone's favorite app this year was – well, you'll just have to [find out for yourself](https://selfh.st/survey/2026-results/#favorite-software).

In actual news and activity:

- **Home Assistant** continued their bizarre product naming habits with the [announcement of the Connect AUX-2](https://www.home-assistant.io/blog/2026/11/11/no-device-left-behind-home-assistant-connect-aux-2/?ref=selfh.st), a small box designed to bring smart home capabilities to non-smart devices
- **Unraid**'s latest [v7.4.0 release](https://unraid.net/blog/unraid-7-4-0?ref=selfh.st) finally adds container template support for multiple custom networks and fields for memory limits
- An independent developer recently launched [Vacuula](https://github.com/vacuula/vacuula?ref=selfh.st), a custom server implementation for **Neato** robot vacuums, in response to the [company's decision to phase out cloud services](https://support.neatorobotics.com/en/support/solutions/articles/204000073686-announcement-6th-oct-2025?ref=selfh.st) late last year
- Evgenii Burmakin, the developer of Dawarich, has launched a Discord for self-hosted software devs – [send him a DM](https://discord.com/users/216988665392529408?ref=selfh.st) if you'd like to join!
- **Verisign**, a popular domain registry, [confirmed it will grandfather existing .name domains](https://itp.cdn.icann.org/en/files/consensus-policies/kane-to-fessenden-05-11-2026-en.pdf?ref=selfh.st) after [plans to completely discontinue the TLD](https://domainnamewire.com/2026/09/03/third-level-dot-name/?ref=selfh.st) stirred up some backlash a few months ago
- The world was introduced to [Ram Altman](https://github.com/iainkay/ram-altman?ref=selfh.st), a satirical bash script that sends daily emails to [Sam Altman](https://www.cnet.com/tech/services-and-software/openai-sam-altman-backtracks-ram-shortage/?ref=selfh.st) when your machine has unused RAM

## Content Spotlight

Meet **plMail**, a self-hosted Gmail-style mail client. Built for users who either self-host their email or are just looking for an interface to unify multiple accounts, **plMail** provides a refreshing, modern take on webmail with an added emphasis on calendars via a docked side panel. Features include support for multiple account types (IMAP, Gmail, Outlook), advanced search, filter trees, optional AI features, and single sign-on.

**plMail** can be [easily deployed via Docker](https://github.com/karatektus/pl_mail?ref=selfh.st#docker#sh=spotlight&name=plMail) and requires separate worker, database, and notification containers.

## Command Line Corner

Use **&&** to run multiple commands under the condition that commands after **&& **will** **only run if the preceding command is successful (most commonly used to execute **apt update** and **apt upgrade** in a single command):

```bash
$ sudo apt update && sudo apt upgrade
```
